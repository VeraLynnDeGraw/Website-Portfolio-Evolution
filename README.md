# Website Portfolio Evolution

A standalone portfolio exploring software projects, thoughtful engineering,
and responsible technology.

## Live Website

https://website-portfolio-evolution.web.app/

## Technology

- HTML
- CSS
- JavaScript (where needed)

## Local Preview

Open `index.html` in a browser, or serve the directory with a local static
web server.

## Hosting

The site is configured for the Firebase Hosting site
`website-portfolio-evolution` in the `wesite-template` Firebase project.

Deployment is maintained by the repository owner. No deployment credentials
are included in this repository.
